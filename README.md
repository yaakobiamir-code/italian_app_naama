# 🇮🇹 Italiano · נעמה – לקראת B2 (TEST ITA L2 / CILS / CELI) עד מרץ 2027

אפליקציה לטלפון ללימוד איטלקית, שנבנתה על אותה שיטה ואותו מחקר כמו האפליקציה [Italian_app](https://github.com/yaakobiamir-code/Italian_app) (חזרה מרווחת FSRS, קלט מובן, דיבור עם משוב מתקן, הסברים קצרים בעברית), ומותאמת לנעמה:

- 🔎 **מבחן אבחון** בפתיחה (34 שאלות, 2 לכל נושא שנלמד בקורס) – קובע מה לחזק קודם.
- 📚 **שלב 1 – חיזוק:** 17 נושאים לפי רשימת הקורס (אלפבית ואיות, שמות עצם ותארים, essere/avere, יידוע, c'è/ci sono, הווה, פעלים לא רגולריים, mi piace, משפחה ושייכות, מודאליים ושעות, מילות יחס, בית, זמן ומזג אוויר, פעלים חוזרים) – ~300 מילים ו-~230 תרגילים שנכתבו ידנית.
- 🪜 **שלבים 2–4:** A2 (passato prossimo, כינויים, עתיד) ← B1 ← B2, כולל "לימודים באוניברסיטה" ו"רפואה ומדעים". מילים ותרגילים ל-B1–B2 מוכנים ע"י המורה (AI) לפי שכיחות.
- ✏️ **תרגילים לפי נושא:** השלמה, הטיית פעלים, מילות יחס, יידוע, איות מהשמיעה, הבנת הנשמע – כולם בחזרה מרווחת; מה שטעית בו חוזר מהר יותר.
- 🗣️ **שיחות עם מורה AI** ב-21 תרחישים (כולל מזכירות האוניברסיטה, ראיון מטופל, בחינה בעל-פה), תיקון עם הסבר קצר בעברית, הרמה עולה בהדרגה.
- 🎓 **הכנה למבחן:** סימולציית **TEST ITA L2** (מבחן האוניברסיטאות של CISIA: 3 חלקים × 40 דק', עם שעון), וחמשת החלקים של CILS B2 / CELI 3 – האזנה, קריאה, מבנים, כתיבה, דיבור – עם ציון וספי המעבר של כל מבחן.
- 📊 **מעקב:** שליטה לפי נושא ולפי רמה (A2 → B1 → B2), ספירה לאחור למבחן, תוכנית שבועית, ותחזית שעות (קורס + אפליקציה).
- 📒 **מסונכרן עם הקורס בסוזי אקדמי:** סימון "נלמד בשיעור" מקפיץ נושא לראש התרגול; הוספת נושאים ומילים חדשים בכמה שניות; תזכורת בימי השיעור.
- ⏱️ **15–20 דקות ביום:** תרגול + פעילות אחת שמתחלפת לפי היום.

על השיטה וההתאמה: [RESEARCH.md](RESEARCH.md) (סעיף 7 – ההתאמה לנעמה; סעיף 8 – מחקר על המבחנים, הקורס והשילוב).

## 🚀 הפעלה ראשונה (פעם אחת, מהמחשב)

### 1. פרסום (GitHub Pages, חינם)
1. ב-GitHub: `https://github.com/yaakobiamir-code/italian_app_naama` ← **Settings**.
2. ה-repo כרגע **פרטי**. GitHub Pages חינם רק ל-repo ציבורי: Settings ← General ← Danger Zone ← **Change visibility** ← Public. (אין בקוד מידע אישי או סודי; ההתקדמות והמפתח נשמרים רק בטלפון.)
3. Settings ← **Pages** ← Source: **Deploy from a branch** ← בחרו את הענף `claude/naama-italian-app` (או `main` אחרי מיזוג), תיקייה `/ (root)` ← **Save**.
4. אחרי 1–3 דקות תופיע הכתובת: **`https://yaakobiamir-code.github.io/italian_app_naama/`**

### 2. התקנה בטלפון של נעמה
- **אייפון:** לפתוח ב-Safari ← שיתוף ⬆️ ← **"הוסף למסך הבית"**.
- **אנדרואיד:** לפתוח ב-Chrome ← ⋮ ← **"התקן אפליקציה"**.

### 3. מפתח AI משלה (לשיחות, למבחן ולתרגילי B1–B2)
1. `console.anthropic.com` ← הרשמה ← **Billing**: לטעון 5$ ← **Limits**: מגבלה חודשית (למשל 3$).
2. **API Keys** ← Create Key ← להעתיק (מתחיל ב-`sk-ant-`).
3. באפליקציה: **התקדמות ← הגדרות** ← להדביק ← "שמירה ובדיקה".

💰 עם Claude Haiku 5.5 (ברירת המחדל): כמה סנטים עד כחצי דולר בחודש בשימוש של 20 דקות ביום.

### 4. בהגדרות
- **אילו מבחנים** (TEST ITA L2 / CILS / CELI) ו**ימי השיעור** בקורס.
- **תאריך המבחן** – ברירת המחדל 15.3.2027. כשיהיה תאריך רשמי, לעדכן (הספירה לאחור והתוכנית השבועית מתעדכנות).

## 🛠️ טכני
- PWA סטטית (HTML/CSS/JS, בלי build), עובדת גם בלי אינטרנט (חוץ מה-AI).
- `js/data.js` – תוכן הקורס של נעמה (יחידות, תרגילים, תרחישים); `js/base.js` – התוכן המקורי שממנו נלקחו יחידות A2/B1/B2.
- `js/store.js` – אחסון, סדר הלמידה, שליטה לפי נושא, תוכנית שבועית. `js/srs.js` – FSRS-4.5. `js/ai.js` – Claude API (פרופיל לומדת, תרגילים, משימות מבחן וציון).
- הרצה מקומית: `python3 -m http.server` ופתיחת `http://localhost:8000`.
